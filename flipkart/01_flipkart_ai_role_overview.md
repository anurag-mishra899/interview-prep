# Flipkart AI Engineer Role - Overview & Context

## Company Context (2026)

### AI Transformation Charter
- **Leadership**: Hemant Badri leads Flipkart's AI Transformation Charter
- **CEO Vision**: Kalyan Krishnamurthy states AI is "no longer experimental" - it's fundamental to operations
- **Strategic Phase**: Shifting from AI strategy to execution ahead of potential IPO
- **Timeline**: Your interview is happening during a critical transformation phase

### OneTech Initiative
- Unified engineering, product, and data teams framework
- Replacing legacy infrastructure with **AI-first architecture**
- Focus on LLMs and agentic frameworks
- Modernizing for scale and IPO readiness

### Tech Stack
**Core Technologies:**
- Python, Java for backend
- Apache Spark for distributed processing
- React, Angular for frontend
- SQL, MongoDB, DynamoDB for data stores
- Redis, HBase for caching and real-time data
- Tableau, Power BI, Google Analytics for analytics

**AI/ML Stack:**
- LLMs (Large Language Models) and SLMs (Small Language Models)
- RAG (Retrieval-Augmented Generation) workflows
- Agentic AI frameworks
- NLP for chatbots and search
- Real-time inference at massive scale

## Role Responsibilities

### Staff AI Engineer Focus Areas
1. **Define technical roadmap** for AI Transformation Org
2. **Build production-grade applications** using LLMs
3. **Implement RAG and agentic workflows**
4. **Solve scale challenges**: hardware optimization, massive inference loads
5. **Full SDLC management** from design to deployment

### Key AI Applications at Flipkart

**1. Personalization & Recommendations**
- ML models analyze: search patterns, size preferences, purchase history, conversion rates
- Mira (AI shopping assistant): 12% increase in cart additions

**2. Fraud Detection**
- Real-time pattern analysis across accounts
- Bot detection using captchas, rate limiting, device fingerprinting
- Anomaly detection for unusual purchase patterns
- Multi-signal processing in seconds

**3. Dynamic Pricing**
- Real-time price adjustments based on demand, competition, customer behavior
- SKU matching with competitor listings
- Catalogue sanitization and labeling

**4. Delivery Optimization**
- 98% address classification accuracy
- 3+ hours saved per delivery hub
- Route optimization using ML

**5. Search & Discovery**
- Conversational search powered by NLP
- Handles billions of searches
- Intent modeling and real-time personalization

**6. NLP & Customer Service**
- Chatbots with continuous learning
- Real-time query resolution
- Virtual assistant integration

## Interview Expectations

Based on the prep guide, you'll be evaluated on:

### What They're Looking For
✅ **Strong software engineering fundamentals**
✅ **Distributed systems expertise**
✅ **Production-ready system design**
✅ **Not just API stitching**

### What They're NOT Looking For
❌ Simple ML model deployment
❌ Basic API integration
❌ Theoretical knowledge without practical scaling

### Core Concepts to Emphasize
- Concurrency and parallelism
- System decoupling and microservices
- Horizontal scaling strategies
- Fan-out architectures

- Async processing patterns

- Resiliency patterns
- Feedback loops and observability
